# ふたりの安否

生野区と旭区で離れて暮らす二人が、有事に安否を確かめ合うためのアプリです。

- 安否ボタン（無事／ケガあり／助けて）、ひとことメモ、電池残量
- 相手の最新状況（6時間以上更新がないと赤く表示）
- 有事モード（6時間ごとに送り直しを促す）
- ルール（SMS用の文、災害用伝言ダイヤル171の手順）
- 生野区・旭区の災害時避難所の一覧（「ここにいる」で相手に伝わる）
- ホーム画面に追加すると、ネットがなくても開ける。電波がない間に送った安否は、つながった時に自動で送られる

二人の安否データはこのリポジトリには入りません。Firebaseに保存され、同じ合言葉を知っている人だけが読めます。

## 準備（最初に一度だけ）

### 1. Firebaseを用意する
1. https://console.firebase.google.com を開き、「プロジェクトを作成」（名前は何でもよい。Googleアナリティクスはオフでよい）
2. 左メニュー「構築」→「Authentication」→「始める」→「ログイン方法」で **匿名** を有効にする
3. 左メニュー「構築」→「Firestore Database」→「データベースの作成」。場所は `asia-northeast2（大阪）`、「本番環境モード」で作成
4. Firestoreの「ルール」タブを開き、このリポジトリの `firestore.rules` の中身をすべて貼り付けて「公開」
5. 歯車アイコン →「プロジェクトの設定」→「マイアプリ」でウェブアプリ（`</>`）を追加し、表示された `firebaseConfig` の値を `firebase-config.js` に貼り付けてコミットする

### 2. GitHub Pagesで公開する
1. リポジトリの「Settings」→「Pages」
2. 「Source」を `Deploy from a branch`、ブランチを `main`、フォルダを `/ (root)` にして保存
3. 数分後に https://june08245.github.io/anpi/ で開けるようになる
4. Firebaseの「Authentication」→「設定」→「承認済みドメイン」に `june08245.github.io` を追加する

### 3. 二人で使い始める
1. 片方がアプリを開き、呼び名を入れて「合言葉を作る」→「はじめる」
2. 合言葉をもう片方に直接伝える（LINEなどで）
3. もう片方も同じURLを開き、自分の呼び名と同じ合言葉を入れて「はじめる」
4. 二人ともホーム画面に追加する（iPhoneはSafariの共有ボタン →「ホーム画面に追加」）
5. 一度「無事」を押し合って、相手の状況が出るか確かめる

## 知っておくこと
- スマホの通知は、アプリを開いている間しか出ません。有事モードは「開いた時に気づける」ための機能です
- ブラウザのデータを消すと、別人として扱われます。合言葉を入れ直せば、また共有できます
- 避難所の一覧は、大阪市生野区役所・旭区役所のウェブサイトで2026年10月に確認した内容です。年に一度は区のサイトで変更がないか確かめてください
